SCÈNE 01LE MONTAGE DE BASE

Tout ce qu'un plan face caméra demande. Rien de plus.

Pas une usine à gaz : six gestes, dans l'ordre où tu les fais. L'interface reprend les habitudes de Final Cut Pro (bibliothèque, visionneuse, inspecteur, timeline, mêmes raccourcis).

Rogner

✂

Couper dans le texte

Barre un mot de la transcription, le passage disparaît de la vidéo.

⌫

Sous-titrer

Transcription locale avec Whisper, corrigeable ligne par ligne, export SRT.

Exporter

SCÈNE 02MONTAGE PAR LE TEXTE

Monter comme on corrige un texte.

Clique sur les mots à enlever. Dans le studio, la vidéo suit : les coupes tombent dans les silences, avec un fondu de son de 10 ms.
